---
title: Multitenancy module
description: Tenant management and database configuration via the Multitenancy module in FullStackHero.
---

The Multitenancy module manages tenant lifecycle and storage.

## Tenant APIs

- Create, update, and delete tenants.
- Configure connection strings and tenant-wide settings.
- Control tenant activation state.

## Persistence

Tenants and their database configuration are stored in the database so the platform can resolve the correct connection string at runtime.
