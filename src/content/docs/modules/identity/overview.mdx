title: Identity module
description: Authentication, authorization, users, roles, and permissions in the FullStackHero Identity module.
---

The Identity module provides authentication and authorization endpoints for your APIs and UIs.

## Capabilities

- User and role management APIs.
- Permission-based authorization and policy helpers.
- Token issuing endpoints with optional rate limiting.

## Integrations

- Works with the multi-tenant infrastructure so users are scoped to tenants.
- Emits audit logs for sensitive operations.

Extend this module when you need custom claims, external identity providers, or additional authorization rules.
