title: Web building block
description: The Web building block configures the HTTP host, pipeline, routing, versioning, and OpenAPI.
---

The Web building block is responsible for wiring the HTTP host and pipeline used by `Playground.Api`.

## Responsibilities

- Configure routing, API versioning, and endpoint discovery.
- Register middlewares for exception handling, multi-tenancy, rate limiting, and OpenAPI.
- Provide helpers to register modules and their endpoints.
