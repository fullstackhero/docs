title: Mailing & storage building blocks
description: Optional building blocks for outbound email and blob/file storage in FullStackHero.
---

Mailing and storage building blocks are designed to be extended per project.

## Mailing

- Common abstractions for sending emails.
- Room for integrating your chosen SMTP or provider-based service.

## Storage

- Abstractions for blob or file storage.
- Ready to be wired to cloud or on-premises storage providers.
